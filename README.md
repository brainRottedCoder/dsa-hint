# DSA Hint

A Next.js based project for providing DSA hints and learning support.

## Getting Started

First, install dependencies:

```bash
npm install
```

Then run the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser to see the result.

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS

## Features

- DSA learning support
- Fast development with Next.js
- Clean UI structure

## Run Locally

Clone the project:

```bash
git clone <repo-link>
```

Move into project directory:

```bash
cd dsa-hint
```

Install dependencies:

```bash
npm install
```

Start server:

```bash
npm run dev
```
